# Скрипт для очистки ленты Twitter/X

Этот скрипт автоматически удаляет ваши собственные твиты и отменяет репосты/ретвиты в ленте Twitter/X с задержками между действиями для имитации человеческого поведения.

## 🚀 Возможности

- ✅ Автоматическое определение собственных твитов и репостов
- ✅ Удаление собственных твитов через меню "More" → "Delete"
- ✅ Отмена репостов через кнопку "Undo repost"
- ✅ Случайные задержки 1-3 секунды между действиями
- ✅ Автоматическая прокрутка для загрузки новых твитов
- ✅ Подробное логирование прогресса
- ✅ Защита от бесконечных циклов
- ✅ Возможность остановки скрипта

## 📋 Как использовать

### Способ 1: Через консоль разработчика (рекомендуется)

1. **Откройте Twitter/X** в браузере Chrome
2. **Перейдите на главную страницу** или в свой профиль
3. **Откройте консоль разработчика**:
   - Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux)
   - Или `Cmd+Option+I` (Mac)
   - Перейдите во вкладку "Console"

4. **Скопируйте и вставьте весь код** из файла `twitter_cleanup_script.js`
5. **Нажмите Enter** для загрузки скрипта
6. **Запустите очистку** командой:
   ```javascript
   cleanupFeed()
   ```

### Способ 2: Bookmarklet

1. **Создайте новую закладку** в Chrome
2. **В качестве URL вставьте**:
   ```javascript
   javascript:(function(){/* ВАШ КОД СКРИПТА */})();
   ```
3. **Нажмите на закладку** находясь на странице Twitter/X

### Способ 3: Chrome Extension (для продвинутых пользователей)

1. Создайте расширение Chrome с манифестом
2. Добавьте скрипт как content script
3. Установите расширение в режиме разработчика

## ⚙️ Конфигурация

В начале скрипта можно изменить настройки:

```javascript
const CONFIG = {
    minDelay: 1000,  // Минимальная задержка (1 сек)
    maxDelay: 3000,  // Максимальная задержка (3 сек)
    maxRetries: 3,   // Количество повторных попыток
    scrollPause: 2000 // Пауза перед прокруткой
};
```

## 🎮 Управление скриптом

### Команды в консоли:

- **Запуск очистки**: `cleanupFeed()`
- **Остановка скрипта**: `stopTwitterCleanup()`
- **Проверка статуса**: `window.cleanupRunning`

### Сообщения в консоли:

- `[Twitter Cleanup]` - обычные сообщения
- `[Twitter Cleanup] ✅` - успешные действия (зеленый цвет)
- `[Twitter Cleanup] ⚠️` - предупреждения
- `[Twitter Cleanup] ❌` - ошибки

## 🔍 Как работает скрипт

1. **Определение пользователя**: Скрипт определяет ваш username для различения собственных твитов
2. **Поиск твитов**: Находит все твиты на текущей странице
3. **Классификация**: Определяет тип каждого твита:
   - Собственный твит → удаление
   - Репост/ретвит → отмена
   - Чужой твит → пропуск
4. **Выполнение действий**: С задержками выполняет соответствующие действия
5. **Прокрутка**: Загружает новые твиты и повторяет процесс

## ⚠️ Важные замечания

### Безопасность:
- Скрипт работает только на доменах `twitter.com` и `x.com`
- Все действия обратимы (можно восстановить твиты из корзины)
- Задержки имитируют человеческое поведение

### Ограничения:
- Максимум 1000 твитов за один запуск (защита от зависания)
- Работает только с видимыми твитами на странице
- Требует активного окна браузера

### Рекомендации:
- Используйте скрипт в нерабочее время
- Следите за консолью для контроля прогресса
- Делайте резервные копии важных твитов

## 🐛 Устранение неполадок

### Скрипт не находит твиты:
- Убедитесь, что находитесь на главной странице Twitter/X
- Попробуйте обновить страницу
- Проверьте, что вы авторизованы

### Ошибки при выполнении действий:
- Twitter/X может изменить интерфейс
- Попробуйте обновить скрипт
- Проверьте интернет-соединение

### Скрипт останавливается:
- Проверьте консоль на наличие ошибок
- Попробуйте запустить заново
- Убедитесь, что окно браузера активно
